First launch

If your computer asks

Windows

Unzip and run TankSiege.exe. If you see “Windows protected your PC”, click More info, then Run anyway.

macOS

Unzip and move Tank Siege to Applications. The first time, right-click the app, choose Open, then Open again. If macOS says the app is damaged, run this in Terminal:
xattr -cr "/Applications/Tank Siege.app"
